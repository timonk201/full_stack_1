# АгроМаркет Express API

## Запуск

```sh
npm install
npm run dev
```

Сервер использует порт `3000` по умолчанию. React-приложение на `http://localhost:5173` разрешено в CORS.

## Маршруты

- `GET /` — короткая проверка доступности сервера.
- `GET /api/health` — статус и время сервера.
- `GET /api/products` — список товаров; необязательный `?search=мёд` фильтрует по названию.
- `GET /api/products/:id` — товар по идентификатору; неизвестный товар возвращает `404`.
- `POST /api/orders` — принимает JSON-заявку с полями `name`, `email`, `phone`, `volume`, `deliveryDate` и необязательным `comment`; успешный ответ имеет статус `201`.

Заявки проверяются на сервере и хранятся в памяти процесса, поэтому очищаются при его перезапуске. Неизвестные маршруты возвращают JSON с ошибкой и статусом `404`.
